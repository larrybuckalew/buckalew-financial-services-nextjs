# Blog Images Directory

This directory is for storing blog post images.

## Adding Images for Blog Posts

1. **Image Naming Convention:**
   - Use the same slug as your blog post
   - Example: For a post with slug `understanding-medicare-comprehensive-guide-2024`
   - Name your image: `medicare-guide-2024.jpg`

2. **Recommended Image Specifications:**
   - **Dimensions:** 1200x630px (optimal for social media sharing)
   - **Format:** JPG or PNG
   - **File Size:** Keep under 500KB for optimal loading
   - **Aspect Ratio:** 16:9 or 2:1

3. **Current Blog Posts Needing Images:**
   - `medicare-guide-2024.jpg` - For "Understanding Medicare: A Comprehensive Guide for 2024"
   - `life-insurance-family-protection.jpg` - For "Life Insurance: Protecting Your Family's Financial Future"
   - `retirement-planning-guide.jpg` - For "Retirement Planning: Start Early, Retire Comfortably"

4. **How to Add Images:**
   - Place your image files in this directory: `/public/images/blog/`
   - Update the blog post data in `/src/lib/blog.ts` if needed
   - The blog posts will automatically display the images

## Image Placeholder

If no image is provided, blog posts will display a nice gradient placeholder with an icon and the post title.

## Image Guidelines

- Use high-quality, professional images
- Ensure images are relevant to the content
- Consider using stock photos from sites like:
  - Unsplash (https://unsplash.com)
  - Pexels (https://pexels.com)
  - Pixabay (https://pixabay.com)
- Optimize images for web (compress without losing quality)

## Tools for Image Optimization

- TinyPNG (https://tinypng.com) - For compression
- Canva (https://canva.com) - For creating custom blog images
- Squoosh (https://squoosh.app) - For format conversion and optimization
